# Report source

The final PDF is generated by `scripts/build_report.py` from measured artifacts under `outputs/`. This keeps tables and headline metrics synchronized with the reproducible experiment outputs. The report intentionally distinguishes published benchmark figures from this project’s own results and records the exact evaluation protocol.

The report's project links include the student's [YouTube demonstration](https://youtu.be/g8qN6C-GF6k), the GitHub repository, and the live application. Run `python scripts/build_report.py` to reproduce the PDF with those links; use `--video-url` only to replace the recording URL.
