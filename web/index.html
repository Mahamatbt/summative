This public app uses the exported learned weights of the same Python model. The source repository contains the full training and evaluation workflow.

How the classifier works

The model breaks words into character patterns, weights them with TF-IDF, and applies a linear support-vector machine trained on Hausa sentiment labels. Six configurations were compared on validation macro F1 before the winner was refitted and tested. It does not call a chatbot or a hosted classifier.

Data, privacy, and limitations

NaijaSenti contains naturally occurring social-media messages, with dataset labels supplied by human annotators. It is released under CC BY 4.0. Your input is processed in this browser; this app does not send it to a prediction server. Results describe one dataset, rather than every Hausa variety or use case. The model is intended for education and low-stakes research.
